# Alex Creations | Web Apps Portfolio

Welcome to the central repository for my web applications, interactive tools, and software distribution pages. 

## About the Developer
I am Alex Sakha, a software developer and final-year engineering student with a strong focus on modular software architecture and minimalist UI/UX design. My projects explore the intersection of clean engineering and frictionless user experiences. I actively build tools that adhere to a strict "Google Antigravity" design philosophy—prioritizing pure edge-to-edge white canvases, functional typography, and zero dashboard bloat.

## About This Repository
This `Web_Apps` repository acts as a unified hub and automated hosting environment (via GitHub Pages) for my frontend projects and application landing pages. Each project is contained within its own dedicated directory, allowing for isolated development while maintaining a cohesive portfolio structure.
